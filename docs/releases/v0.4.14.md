답장노트 0.4.14 베타입니다. 0.4.4 이후 로컬에서 작업한 기능과 최신 대화 화면을 Mac·Windows 배포 파일에 반영했습니다.

### 이번 버전의 변경
- 별도 **원문·사진·파일 연결** 섹션을 제거했습니다. 사진·파일 메시지에서 **직접 파일 선택**, 연결 확인·해제를 처리합니다. 파일을 해당 메시지에 끌어놓아 연결할 수도 있습니다.
- 질문 아래 **원문 보기·연결**에서 답장 원문과 보충 설명을 지정합니다. 기존 자료와 초안 출처 정보는 유지합니다.
- macOS의 **카톡에서 가져오기 · 실험**으로 단일 사진·파일 원본 저장과 메시지 연결을 시도할 수 있습니다. 나와의 채팅 첨부도 지원합니다. 실행 중 카톡 창이 잠깐 활성화됩니다.
- 최근 대화의 사진·파일을 감지하고, 내용을 읽지 못한 자료가 있으면 초안 생성을 보류합니다. 일반 텍스트 말풍선을 사진으로 오인하던 macOS 분류를 수정했습니다.
- PNG/JPG/WebP, PDF, DOC/DOCX, HWP/HWPX, TXT/MD/CSV 자료를 지원합니다. 파일당 10MB, 질문당 4개, PDF는 파일당 5쪽까지입니다.
- Windows 문서·이미지 분석에 필요한 Windows x64용 라이브러리를 설치 파일에 포함했습니다.
- 단체방의 질문자·선생님 등록, 질문자별 초안 생성, 선생님 응답 시 진행 작업 취소, 사람별 프롬프트를 포함합니다.
- 초안 수정·저장·재작성, 알림, macOS 1:1/나와의 채팅에 사용자가 직접 요청하는 전송 기능을 포함합니다. 상대방에게 자동 전송하지 않습니다.

### 설치와 업데이트
- **Mac Apple Silicon:** 실행 중인 앱을 메뉴에서 완전히 종료한 뒤 ZIP을 풀고 기존 앱을 대치하세요. 손쉬운 사용 권한을 다시 확인해야 할 수 있습니다.
- **Windows 10/11 x64:** 트레이에서 앱을 종료하고 새 설치 파일을 기존과 같은 위치에 설치하세요.
- 일반적인 덮어쓰기 설치에서 설정·기록은 유지됩니다. 다운로드만으로 실행 중인 이전 앱이 교체되지는 않습니다.
- OS에 설치되고 로그인된 Codex CLI와 카카오톡이 필요합니다. 초안 생성 시 대화·프롬프트·연결한 문서 내용과 이미지가 OpenAI 서비스로 전달됩니다.

### 검증과 알려진 제한
- 타입 검사, 자동 테스트 184개, macOS 파서 검사 22개와 패키지 데모 UI 검사를 수행했습니다. 데모에서 사진·파일 연결, 원문 저장, 생성 보류, 자료를 사용한 초안, 연결 해제, 원본 가져오기의 연결·분석 경로를 확인했습니다.
- 실제 나와의 채팅에서 카톡 UI를 통한 PDF·JPEG 원본 저장을 확인했습니다. 새 네이티브 가져오기 버튼의 실제 카톡 전체 과정은 추가 실기 검증이 필요합니다. 묶음 사진·정체가 불확실한 첨부는 직접 파일 선택을 사용하세요. 만료되거나 저장할 수 없는 첨부는 가져오지 못할 수 있습니다.
- Windows 원본 자동 가져오기·직접 전송은 제공하지 않으며, 실제 Windows 카톡 연결은 시험 지원 상태입니다. Windows 설치 파일은 macOS에서 교차 빌드합니다.
- 앱 교체 후 초기 실행에서 흰 화면이 한 차례 관찰되었으며 완전 종료 후 재실행으로 복구되었습니다. 정확한 원인은 아직 특정하지 못했습니다.
- Mac은 ad-hoc 서명이고 Developer ID 서명·공증은 설정하지 않았습니다. Windows 배포 서명도 설정하지 않았습니다.

설치 파일의 SHA-256은 **SHA256SUMS.txt**에서 확인할 수 있습니다.
